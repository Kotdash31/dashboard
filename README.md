#### *В данном проекте был создан дэшборд, отражающий метрики KPI и динамику роста показателей товарной категории.*


**Требования к дэшборду:**  
Дэшборд должен помочь проанализировать данные и дать ответ на следующие вопросы:
- Какой рост выручки в сравнении с прошлым месяцем? (учесть планове значение не менее 5% MoM)
- Какой процент выкупа? (учесть плановый показатель в 95%)
- Какой рост выручки по категории, по брендам?
- Какие основные тенденции наблюдаются?
- Какая зависимость наблюдается между процентом выкупа и стоимостью товара?

**Набор данных:**  
    *Таблица 1 (csv*) - данные по продажам, выручке, % выкупа по брендам и по месяцам.   
    *Таблица 2 (csv)* - данные по SKU (SKU, подкатегория, бренд, цена за 2 последних месяца (декабрь, ноябрь), выручка, средний % выкупа, страна производитель.

    
**Создание дэшборда:**
1. Сбор требований и создание канвы (в каких ситуациях и кем будет использоваться дэшборд, какие проблемы должен помочь решить, на какие вопросы ответить, какие данные имеем и их особенности, какие типы графиков будут использоваться)
#### [Посмотреть канву](https://drive.google.com/drive/u/2/folders/1mbSFYoaro2YRrq_SK0mgQIX-T2jovXDJ)
2. Подготовка данных - чистка данных от лишнего и пустых значений, приведение к нужному типу, аггрегация, фильтрация, создание новых калькуляций.
3. Построение графиков
4. Верстка дэшборда
